# Elio

Elio 是一个使用原生 JavaScript 开发的轻量个人任务管理器。任务数据保存在浏览器本地，不需要注册账号或连接服务器。

## 功能

- 新增和删除任务
- 双击任务标题即可编辑内容（Enter 保存，Esc 取消）
- 键盘聚焦任务标题后按 Enter 或空格进入编辑；失焦保存，空白内容保留原标题
- 标记任务完成状态
- 查看待完成任务数量
- 按全部、待完成和已完成筛选
- 使用 localStorage 持久化任务数据
- 支持桌面端和移动端布局
- 支持键盘操作和基础无障碍标签

## 技术栈

- HTML5
- CSS3
- JavaScript
- Vite
- Web Storage API

## 本地运行

需要安装 Node.js 20.19–20.x，或 Node.js 22.12 及以上版本。

安装依赖：

```bash
npm ci
```

启动开发服务器：

```bash
npm run dev
```

根据终端提示访问本地地址，通常为：

```text
http://localhost:5173/
```

## 构建项目

```bash
npm run build
```

构建结果会生成在 `dist` 目录。

运行项目检查：

```bash
npm test
```

该检查会执行生产构建，确认项目可以被正常解析和打包。
它不是功能测试，也不能代表外部平台准入检查通过。

浏览器回归测试（首次需安装 Chromium）：

```bash
npx playwright install chromium
npm run test:e2e
```

Linux CI 可用 `npx playwright install --with-deps chromium` 安装浏览器及系统依赖。
测试自动启动 4173 端口的开发服务器，覆盖任务增删、编辑、完成、筛选、刷新持久化、异常存储与窄屏布局。

本地预览构建结果：

```bash
npm run preview
```

## 验收检查

提交前先运行生产构建：

```bash
npm run build
```

随后在本地页面依次确认：

1. 可以使用按钮或回车新增任务，空白内容不会被提交。
2. 可以切换任务完成状态，待完成数量同步更新。
3. “全部”“待完成”“已完成”筛选结果正确。
4. 刷新页面后，任务及完成状态仍然保留。
5. 删除任务后，列表、数量和空状态同步更新。
6. 在窄屏设备上表单和筛选区域不会产生横向滚动。

## 使用说明

1. 在输入框中填写任务内容。
2. 点击“添加任务”或按回车创建任务。
3. 勾选任务左侧复选框，将任务标记为已完成。
4. 使用“全部”“待完成”和“已完成”按钮筛选任务。
5. 点击“删除”移除不再需要的任务。
6. 刷新页面后，任务仍保存在当前浏览器中。

## 数据与隐私

任务仅保存在当前浏览器的 localStorage 中。项目不会将任务发送至服务器，也不会收集用户个人信息。

清除浏览器网站数据后，本地任务也会被删除。
存储失败时页面显示提示，未保存的修改仅存在于当前页面；格式异常的本地记录会被跳过，后续成功保存会写入当前有效任务。

## 已知限制

- 暂不支持跨设备同步
- 暂不支持账号登录
- 暂不支持任务截止日期
- 暂不支持导入和导出
